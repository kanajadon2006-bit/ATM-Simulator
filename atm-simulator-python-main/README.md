
# 🏦 ATM Simulator (Python Project)

A simple command-line ATM simulator built using Python.

## 💡 Features

- 🔐 PIN authentication with 3 login attempts
- 💰 Check balance
- 📥 Deposit funds
- 💸 Withdraw funds
- 🧼 Menu-driven interface using loops and conditionals

## 🛠 Technologies Used

- Python (basic programming concepts)

## 🚀 How to Run

1. Clone or download this repo.
2. Open a terminal in the folder.
3. Run the script using:

```bash
python atm_simulator.py
```

## 📚 Learning Outcomes

- Practiced control flow with loops and conditionals
- Implemented user authentication and input validation
- Built an interactive console application
